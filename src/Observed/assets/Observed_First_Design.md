# 2D게임 프로젝트 간단 기획

## 요약
- 방(실험실)에서 하루하루 재화를 벌며 욕구를 관리해 살아남는 게임

## 시점
- 탑다운 뷰

## 컨셉
- 취미가 고약한 부자들로 인해 어떤 방에 갇힌 플레이어는 매일매일 살아남아야 한다.

## 게임 엔딩 방식
- 클리어 O : 살아남는 날의 한도(ex: 열흘 동안 살아남기)를 정한다.
	- 초반 며칠은 살아남기 쉽지만, 날이 갈 수록 재화 제한, 욕구 하락 속도 증가등으로 살아남기 어렵게 함
- 클리어 X : 한도 없이 최대한 오래 살아 남는 게 목표
	- 게임 클리어 후 살아남은 일수를 기록으로 남겨 기록 갱신 가능
---
## 핵심 시스템

### 플레이어
- 상태
	- 시간이 지나면 감소
		- 포만감(식욕) : 과하게 먹거나 너무 안 먹으면 질병 스택 +1
		- 수분(갈증) : 과하게 마시거나 너무 안 마시면 질병 스택 +1
		- 에너지(수면욕) : 0이 될 시 강제 블랙 아웃
	- 조건부 발동
		- 질병(디버프) : 포만감, 수분, 에너지 게이지가 스택에 따라 특정 배수만큼 더 빠르게 감소

### 아이템 : 게임으로 획득
- 식량 : 상호작용 시 포만감/수분 게이지가 참
	- 고기(100g 단위, 포만감 +10, 하루 최대 제공량 : 500g) : 3시간이 지나고 먹을 시 특정 확률로 질병에 걸릴 수 있다
		- 신선한 고기 : 시간이 지나지만 않으면 부작용이 없는 고기
		- 수상한 고기 : 포만감 게이지는 차지만, 누적해서 섭취할 경우 질병에 걸릴 수 있음
	- 식수(100mL 단위, 수분 +10, 하루 최대 제공량 : 500mL) : 2~3일 지나고 먹을 시 특정 확률로 질병에 걸릴 수 있음
	- 수면권(2시간 단위, 하루 최대 제공량 : 6시간) : 붙여잘수록 에너지 회복량이 높아지고, 시간이 끝나면 강제기상된다

### 맹수 우리 : 플레이 중 긴장감을 주기 위한 장치 (실제 추격전 X)
- 상태
	- 공격성
		- 시간이 지나면 증가(조건부 감소)
		- 고기 100g 섭취시 -10
		- 100 이상일 시 우리 탈출
			- 아래 공격 확률에 따라 게임 오버될 확률도 있음
			- 하루나 이틀 뒤엔 새로운 맹수가 스폰됨
	- 공격 확률 : 
		- 0에서 조건부 증가
		- 수상한 고기 100g 섭취 시 +5

### 미니 게임(후보 중 택2) : 게임기를 통해 플레이 가능(즉 게임기 오브젝트가 필요), 클리어시 포인트 획득
- 후보
	1. 페어 매칭
	1. 타이밍 맞추기
	1. 순서 기억하기
	1. 두더지 잡기
	1. 슬롯머신
	1. 분류게임(같은 그림 3개)

### 교환 자판기 : 모아둔 게임 포인트를 아이템으로 교환
- 목록
	- 아이템(고기, 식수, 수면권)
	- (낮은 확률로)부자의 후원 : 포인트 대가 없이 아이템을 랜덤으로 받을 수 있음
