# PICO PARK 모작 컨셉 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 최대 4명이 한 방에 접속해, 서로 힘을 합쳐야만 풀리는 방을 탈출하는 협동 퍼즐 플랫포머 |
| 장르 | 2D 협동 퍼즐 플랫포머 |
| 시점 | 사이드뷰 (2D, 고정 카메라) |
| 플레이 인원 | 2~4인 (호스트 1 + 참가자 최대 3) |

---
## 2. **핵심 재미**

- 혼자서는 절대 풀 수 없고, 반드시 다른 플레이어와 동시에 행동해야 다음 구간으로 갈 수 있다는 데서 오는 "협동 그 자체가 퍼즐"인 재미.
---

## 3. 화면 구성 및 씬 흐름

```
[타이틀] → [닉네임 입력] → [방 생성/코드 입력] → [대기실(참가자 목록)]
   → [스테이지 1] → [스테이지 2] → [스테이지 3] → [클리어 화면 / 기록 조회]
```

- 대기실: 방 코드 표시, 참가자 아바타 및 준비 상태 표시
- 인게임 UI: 최소화 (플레이어 이름표, 남은 목표 안내 정도)

## 4. 코어 루프

```
1. 스테이지 진입 → 전원 시작 지점에 스폰
2. 구간별 기믹 관찰 (예: 두 명이 동시에 스위치를 밟아야 문이 열림)
3. 역할 분담 대화(음성 / 텍스트 대화 추가 염두)
4. 실패 시 즉시 재시도 (페널티 없음, 리스폰 즉시)
5. 성공 → 다음 구간 → 최종 탈출 시 클리어 화면
```

---

## 5. 선택 주제 및 선정 이유
- **선정 주제**: 주제 2 — 방 코드 입력형 4인 멀티플레이 게임
- **선정 이유**
  - 강사 제공 샘플(위치 동기화, 채팅, 유저 데이터)을 그대로 활용할 수 있어 초·중급 인원 4인 구성에 적합
  - 서버 권위 로직이 주제 3(보드게임)만큼 복잡하지 않고, 좌표 동기화 + 간단한 오브젝트 상태(스위치 on/off) 정도로 구현 범위를 좁힐 수 있음
  - PICO PARK 특유의 "동시 입력 퍼즐" 구조가 방탈출/협동 예시 방향과 자연스럽게 맞음
