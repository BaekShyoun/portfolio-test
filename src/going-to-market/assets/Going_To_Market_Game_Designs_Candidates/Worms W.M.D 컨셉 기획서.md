# Worms W.M.D 모작 컨셉 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 무작위로 생성된 2D 지형 위에서, 1:1로 매칭된 상대와 턴을 주고받으며 다양한 무기로 상대 유닛을 전멸시키는 턴제 포격 대전 |
| 장르 | 2D 턴제 포격 전술 대전 |
| 시점 | 사이드뷰 (2D, 고정 카메라) |
| 플레이 인원 | 1:1 (팀당 유닛 2~3기) |

---
## 2. **핵심 재미**

- 내 턴에 주어진 제한 시간 안에 바람·지형·탄도를 계산해 최선의 한 방을 쏘고, 상대의 턴에는 다음 수를 읽으며 대비하는 "생각하는 실시간 긴장감"의 재미. 운(무기 상자, 바람)과 실력(조준, 지형 활용)이 함께 작용해 역전이 자주 일어난다.
---

## 3. 화면 구성 및 씬 흐름

```
[타이틀] → [닉네임 입력] → [매칭 시작(대기열 등록)] → [매칭 대기 화면(취소 가능)]
   → [룸 생성 및 대전 시작] → [전투 진행 (턴 교대)]
   → [한쪽 팀 전멸 시 승패 판정] → [결과 화면 / 전적 조회]
```

- 매칭 대기 화면: 대기 시간 표시, 취소 버튼, 타임아웃 시 자동 취소 및 안내
- 인게임 UI: 현재 턴 표시, 턴 제한 시간 타이머, 선택 무기, 각 유닛 체력

## 4. 코어 루프

```
1. 매칭 완료 → 무작위 지형 생성 → 양 팀 유닛 배치
2. 내 턴 시작 → 유닛 이동/조준 → 무기 선택 후 발사 (제한 시간 내)
3. 턴 종료 → 상대 턴 진행 (서버가 턴 순서 강제)
4. 지형 파괴·유닛 피해 반영 → 체력 0인 유닛 제거
5. 한쪽 팀 유닛 전원 사망 시 즉시 종료 → 결과 판정 및 서버 저장
```

---

## 5. 선택 주제 및 선정 이유
- **선정 주제**: 주제 1 — 매치메이킹 기반 1:1 대전 게임
- **선정 이유**
  - 실시간 좌표 동기화가 필요 없는 **턴제 구조**라 난이도 가 비교적 낮음
  - 매칭 대기열 → 룸 생성 → 결과 저장·재접속 조회라는 주제 1 필수 요구사항이, 강사 제공 유저데이터 샘플과 자연스럽게 맞물림
  - 난이도 포인트(대기 취소·타임아웃, 상대 이탈 처리)가 게임 콘텐츠 난이도와 분리되어 있어, 무기 종류·지형 파괴 등 콘텐츠 스코프를 자유롭게 줄여도 필수 요구사항 충족에는 지장 없음
